# T2Pilt

T2Pildi veebiprototüüp GitHub Pagesi jaoks. Ava veebileht HTTPS-aadressil ja luba kaamera ning asukoha kasutamine.

OpenStreetMapi Nominatimi päring on katsetamiseks; Teeregistri ja Maa- ja Ruumiameti teenused ei ole veel ühendatud. Avaliku Nominatimi teenuse kasutustingimusi ja päringupiiranguid tuleb järgida.
