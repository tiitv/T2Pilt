# T2Pilt 0.4.2

Paigalda **mõlemad** failid GitHubi repositooriumi juurkausta:
- `index.html` (asenda vana)
- `teeregister-042.js` (uus failinimi; ära nimeta ümber)

Uus failinimi väldib vana `teeregister.js` brauserivahemälu kasutamist. Veendu, et lehel kuvatakse pealkiri **T2Pilt – veebiproov 0.4.2**. Kui endiselt on näha 0.4.1 või 0.4, kasutatakse vana index.html faili või muud avaldamisharu. Ava leht privaatrežiimis või lisa veebilehe aadressile `?v=042`.

Diagnostikas kuvatakse rakenduse ja mooduli versioon. Kui tekib viga, kopeeri kogu diagnostikatekst.

WFS 1.0.0 GPS-päring, 50–600 m otsingualad ja arvutuslik kilometraaž on endised. CORS pole veel tegelikus telefonibrauseris kinnitatud.
